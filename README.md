# Power BI Data Professional Survey Analysis

## Project Overview

This project uses Microsoft Power BI to analyze survey data from data professionals.

The dashboard provides an interactive breakdown of data professional roles, salary levels, geographic distribution, and other survey responses.

## Dashboard

The dashboard is titled:

**DATA PROFESSIONAL SURVEY BREAKDOWN**

It provides interactive visualizations to explore the survey data and compare different aspects of the data professional workforce.

## Analysis

The dashboard analyzes areas such as:

- Data professional job titles
- Average salary by job title
- Survey participant count
- Country distribution
- Professional background
- Survey responses and demographic information

## Key Visualization

One of the dashboard visuals compares **average salary across different job titles**, helping identify salary differences between data-related roles.

The dashboard also includes a survey participant count and interactive filtering.
